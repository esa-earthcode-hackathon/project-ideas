# ESA EarthCODE Hackathon 2026 Project Ideas

If you have an idea for a project before the hackathon, please post your idea as an [Issue](https://github.com/esa-earthcode-hackathon/project-ideas/issues) here, so others can see it and discuss it. Project ideas don't need to be fully thought-out, even a general idea or theme is a great starting point!

There are issue labels for ![]( https://img.shields.io/badge/carbon-0e8a16), ![](https://img.shields.io/badge/ocean-1d76db), and ![](https://img.shields.io/badge/polar-c5def5) cluster topics. Please label your issues if the labels are relevant to a specific ESA cluster.

If you see an idea that you are interested in, please comment on it to continue the discussion. We will have ample time dedicated to discussing and developing project ideas and forming teams in the first day and a half of the Hackathon.
